# قالب وردپرس المیرا آزمون

همان قالب `elmira-theme`، این‌بار به‌صورت **قالب بلاکی وردپرس** (ویرایش کامل سایت با گوتنبرگ). ظاهر و همهٔ افکت‌ها و تعامل‌ها با نسخهٔ HTML یکی است. متن، تصویر و پیوند همهٔ صفحه‌ها در ویرایشگر بلاک قابل ویرایش است.

- نیازمندی‌ها: وردپرس ۶٫۶ یا جدیدتر (با ۷٫۱ آزمایش شده)، PHP ۷٫۴ یا جدیدتر
- هیچ فایلی از CDN بارگذاری نمی‌شود. فونت‌های وزیرمتن و مرکزی، آیکن‌های Phosphor و CSS ساخته‌شدهٔ Tailwind داخل خود قالب هستند.

## نصب

1. فایل `elmira-azmoon.zip` را از **پیشخوان ← نمایش ← پوسته‌ها ← افزودن ← بارگذاری پوسته** نصب و فعال کنید.
2. به **نمایش ← المیرا آزمون** بروید و «راه‌اندازی سایت نمونه» را بزنید. این کارها انجام می‌شود:
   - برگه‌های طراحی‌شده ساخته می‌شوند: خانه، خدمات، میکاپ عروس، گالری، فروشگاه، صفحهٔ محصول، سبد، تسویه، آموزشگاه، صفحهٔ دوره، ثبت‌نام، درباره، تماس، ورود و پنل کاربری.
   - «خانه» صفحهٔ اصلی می‌شود و «مجلهٔ زیبایی» صفحهٔ نوشته‌ها.
   - منوی اصلی ساخته می‌شود.
   - اگر بخواهید، ۷ مقالهٔ نمونه با دسته، برچسب و دیدگاه هم ساخته می‌شود.
   - اگر پیوندهای یکتا روی «ساده» باشند، روی «نام نوشته» تنظیم می‌شوند.
3. در همان صفحه آدرس **سامانهٔ نوبت‌دهی** را وارد کنید. همهٔ دکمه‌های «رزرو نوبت» به آن می‌روند.
4. زبان سایت را در **تنظیمات ← عمومی** روی فارسی بگذارید تا تاریخ‌ها و پیام‌های وردپرس هم فارسی شوند. قالب در هر حال راست‌به‌چپ است.

## ویرایش محتوا

| چه چیزی | کجا |
|---|---|
| متن‌ها، تصاویر و دکمه‌های هر برگه | ویرایشگر همان برگه. روی متن کلیک کنید و بنویسید. برای عوض کردن تصویر، آن را انتخاب کنید و از نوار ابزار «جایگزینی» را بزنید. پیوند هر دکمه یا کارت در ستون تنظیمات بلاک است. |
| افزودن بخش آماده | افزودنگر بلاک ← الگوها ← دسته‌های «المیرا» (بخش‌های هر صفحه و برگه‌های کامل) |
| منوی سربرگ و منوی موبایل | نمایش ← فهرست‌ها، جایگاه «منوی اصلی». متن «توضیح عنوان» هر آیتم، برچسب آن در منوی موبایل است. |
| پانویس (نشانی، تلفن، شبکه‌های اجتماعی) | نمایش ← ویرایشگر ← الگوها ← قطعه‌ها ← پانویس |
| قالب مقاله، مجله، بایگانی، ۴۰۴ | نمایش ← ویرایشگر ← قالب‌ها |
| مقاله‌های مجله | نوشته‌ها. تصویر شاخص، دسته و برچسب همان‌جا تنظیم می‌شوند. نوشتهٔ «سنجاق‌شده» در بالای مجله، مقالهٔ ویژه می‌شود. |

قالب‌های برگه:

- **بوم کامل:** برای برگه‌های طراحی‌شده. هیروی هر برگه جزو محتوای خود آن برگه است.
- **پیش‌فرض:** برای برگه‌های متنی ساده مثل قوانین. هیروی تیره و عنوان به‌طور خودکار ساخته می‌شوند.
- **بدون سربرگ و پانویس:** برای صفحهٔ ورود.

سبک‌های اضافه برای نوشته‌ها: «پاراگراف آغازین»، «فهرست پرهیز (ضربدر)»، «فهرست تیک‌دار» و الگوی «فراخوان رزرو».

## بلاک‌ها

- **عنصر طراحی (`elmira/el`):** هر تکه از طراحی قالب یک بلاک است، مثل بخش، کارت، تیتر، دکمه یا تصویر. کلاس‌ها و `data-*`ها (افکت‌های ورود، شمارنده، اسلایدر، فیلتر و ...) در این بلاک حفظ می‌شوند. در نمای فهرست، بخش‌ها با نامشان دیده می‌شوند (هیرو، خدمات، فروشگاه، ...). برای کارهای پیشرفته پنل «پیشرفته (HTML)» تگ، شناسه و ویژگی‌ها را نشان می‌دهد.
- **بلاک‌های پویا:** این بلاک‌ها از داده‌های واقعی وردپرس ساخته می‌شوند:
  - سربرگ سایت
  - هیروی صفحه (عنوان و مسیر خودکار)
  - مقاله‌های مجله (جدیدترین‌ها، مقالهٔ ویژه، فهرست بایگانی با صفحه‌بندی)
  - چیپ دسته‌ها، جستجو، پرخواننده‌ترین‌ها، دسته‌بندی‌ها
  - فهرست مطالب خودکار، تصویر شاخص عریض، برچسب‌ها و نویسنده، دیدگاه‌ها، مقالات مرتبط

## محدودیت‌ها

- فروشگاه، سبد، تسویه، ثبت‌نام دوره، ورود و پنل کاربری همان **صفحه‌های نمایشی** قالب HTML هستند. تعامل‌هایشان کار می‌کند ولی سفارش واقعی ثبت نمی‌شود. برای فروش واقعی باید ووکامرس اضافه شود، که قدم بعدی است.
- فرم‌های تماس و خبرنامه نمایشی‌اند و پیام موفقیت نشان می‌دهند. برای ارسال واقعی، فرمی از افزونه‌ای مثل Contact Form 7 را جایگزین کنید.
- عکس‌ها، قیمت‌ها و متن‌های نمونه همان موارد README قالب HTML هستند و پیش از انتشار باید عوض شوند. عکس‌ها از Unsplash لینک شده‌اند.

## ساخت دوباره (برای توسعه‌دهنده)

منبع اصلی طراحی همچنان `elmira-theme/_src` است. بعد از تغییر صفحه‌ها یا CSS/JS قالب HTML:

```bash
cd wordpress/build
npm install      # فقط بار اول
npm run build
```

`npm run build` این کارها را انجام می‌دهد:

1. `convert.py`: صفحه‌ها را به الگوهای بلاکی (`patterns/`) تبدیل می‌کند و قالب‌ها و قطعه‌ها را از `build/src` می‌سازد.
2. `demo_posts.py`: مقاله‌های نمونه را می‌سازد.
3. `vendor.mjs`: فایل‌های `theme.css` و `theme.js` را با چند وصلهٔ وردپرسی کپی می‌کند، همراه با فونت‌ها و آیکن‌ها.
4. Tailwind را کامپایل می‌کند.
5. فایل `elmira-azmoon.zip` را می‌سازد.

فایل‌های `patterns/`، `templates/`، `parts/`، `assets/css/tailwind.css`، `assets/css/theme.css`، `assets/js/theme.js` و `inc/demo-*.{json,php}` ساخته‌شده‌اند و نباید مستقیم ویرایش شوند. کد اختصاصی وردپرس در `functions.php`، `inc/`، `blocks/`، `assets/js/editor.js` و `assets/css/{wp,editor}.css` است.

برگه‌هایی که قبلاً ساخته شده‌اند با ساخت دوباره عوض نمی‌شوند، چون محتوایشان در پایگاه‌داده است. الگوها در افزودنگر به‌روز می‌شوند.
