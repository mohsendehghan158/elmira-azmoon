# قالب المیرا آزمون

قالب HTML کامل سایت سالن زیبایی المیرا آزمون: ۱۸ صفحه، فارسی و راست‌به‌چپ، Tailwind CSS v4، حالت روشن و تیره.

نسخهٔ وردپرس (قالب بلاکی گوتنبرگ) در پوشهٔ [`wordpress`](../wordpress/README.md) است و از همین فایل‌ها ساخته می‌شود.

## صفحه‌ها

| بخش | صفحه‌ها |
|---|---|
| سالن | `index.html` · `booking.html` (لیست خدمات) · `service-single.html` · `gallery.html` |
| فروشگاه | `shop.html` · `product-single.html` · `cart.html` · `checkout.html` |
| آموزشگاه | `academy.html` · `course-single.html` · `enroll.html` |
| عمومی | `blog.html` · `blog-single.html` · `about.html` · `contact.html` · `auth.html` · `account.html` · `404.html` |

## ساختار

```
elmira-theme/
├── *.html                 ← خروجی نهایی (ساخته‌شده؛ مستقیم ویرایش نکنید)
├── assets/css/theme.css   ← توکن‌های رنگ، کامپوننت‌ها و افکت‌ها
├── assets/js/theme.js     ← همهٔ رفتارها و میکرواینتراکشن‌ها
└── _src/
    ├── build.py           ← اسکریپت ساخت
    ├── partials/          ← head، سربرگ، فوتر و اجزای شناور مشترک
    └── pages/             ← محتوای هر صفحه
```

برای تغییر یک صفحه، فایل آن را در `_src/pages` ویرایش کنید و بعد این دستور را اجرا کنید:

```bash
python3 _src/build.py
```

## تنظیمات

- **سامانهٔ نوبت‌دهی:** رزرو نوبت در سایت انجام نمی‌شود. همهٔ دکمه‌هایی که `data-booking` دارند به یک آدرس لینک می‌شوند و در تب جدید باز می‌شوند. آدرس را در `assets/js/theme.js` و در متغیر `BOOKING_URL` بگذارید.
- **رنگ‌ها:** متغیرهای بالای `theme.css` (`:root` برای حالت روشن و `html.dark` برای حالت تیره).
- **Tailwind:** از CDN و به‌صورت کامپایل در مرورگر (`@tailwindcss/browser@4`) لود می‌شود. پیش از انتشار واقعی بهتر است به CSS ساخته‌شده تبدیل شود.

## افکت‌ها و تعامل‌ها

پردهٔ انتقال بین صفحه‌ها، نشانگر سفارشی ماوس، دکمه‌های مغناطیسی، کارت‌های سه‌بعدی، تیتر کلمه‌به‌کلمه، ورود به دید با برش (clip)، پارالاکس، نوار متحرک، شمارنده‌ها، تغییر تم با موج دایره‌ای، سربرگ هوشمند، نوار پیشرفت اسکرول، پرواز محصول به سبد، قلب علاقه‌مندی، اعلان‌ها، کشوی منو و سبد، آکاردئون، تب با خط لغزان، فیلتر و مرتب‌سازی، لایت‌باکس، اسلایدر قبل و بعد، بزرگ‌نمایی تصویر محصول، لغزندهٔ قیمت، کد یکبار مصرف، بارگذاری فایل با پیش‌نمایش، اعتبارسنجی فرم و فهرست مطالب فعال.

همهٔ حرکت‌ها با `prefers-reduced-motion` خاموش می‌شوند. بدون جاوااسکریپت هم همهٔ محتوا دیده می‌شود.

## محتوای نمونه (پیش از انتشار جایگزین شود)

- متن‌هایی که با `[متن نمونه]` یا `[پاسخ نمونه]` مشخص شده‌اند
- نشانی، شمارهٔ تماس، ایمیل، ساعات کاری و شبکه‌های اجتماعی
- مجوزها و نوع و اعتبار مدرک آموزشگاه
- نقشه، که تزئینی است
